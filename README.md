## Цель работы

Расширение программной системы онлайн-школы, разработанной в рамках предыдущего проекта. Реализация перегруженных операторов для сравнения объектов по различным характеристикам, потокового ввода и вывода данных, управления составом курса с контролем предельной вместимости через операторы `+=` и `-=`, а также реализация дружественной функции для прямого доступа к закрытым членам класса.

---

## Структура проекта

- `Header files/student.h` / `Source files/student.cpp` — класс `Student`: закрытые поля (`studentId`, `studentName`, `completedTasks`), оператор равенства (`==`), трехстороннее сравнение (`<=>`), потоковые операторы (`<<`, `>>`) и дружественная функция `inspectStudentInternals`.

- `Header files/course.h` / `Source files/course.cpp` — класс `Course`: перегруженные операторы `+=` и `-=` для зачисления и отчисления студентов, контроль лимита участников (`maxCapacity`), расчет прогресса, а также структура двусвязного списка `CourseList`.

- `Header files/menuFunc.h` / `Source files/menuFunc.cpp` — функции консольного интерфейса (`mainMenu`, `courseMenu`) для управления курсами и студентами.

- `Header files/header.h` — общий заголовочный файл, объединяющий библиотеки и модули проекта.

- `Source files/main.cpp` — точка входа: функция проверки перегруженных операторов и дружественной функции `verifyBasicOperations()`, инициализация начальных данных `populateInitialData()` и запуск главного меню.

---

## Основной функционал

1. **Сравнение объектов по характеристикам:**
   * Реализация оператора равенства (`==`) для сопоставления студентов по уникальному идентификатору `studentId`.
   * Реализация оператора трехстороннего сравнения (`<=>`) стандарта C++20, обеспечивающего автоматическую поддержку операторов `<`, `>`, `<=`, `>=` на основе количества выполненных задач `completedTasks`.

2. **Потоковый ввод и вывод:**
   * Перегрузка оператора `<<` для вывода имени, идентификатора и числа выполненных заданий студента в выходной поток.
   * Перегрузка оператора `>>` для ввода данных о студенте (`studentId`, `studentName`, `completedTasks`) из входного потока с корректной обработкой переносов строк.

3. **Дружественная функция:**
   * Функция `inspectStudentInternals` объявлена как `friend` внутри класса `Student`.
   * Демонстрирует прямой доступ к закрытым полям `studentId`, `studentName` и `completedTasks` в обход методов-геттеров.

4. **Управление составом курса и обработка ограничений:**
   * Перегрузка оператора `+=` для записи студента на курс с проверкой предельной вместимости `maxCapacity` и предотвращением дублирования записей.
   * Перегрузка оператора `-=` для отчисления студента по идентификатору и освобождения места на курсе.
   * Контроль лимитов: при попытке добавить студента сверх вместимости `maxCapacity` операция отклоняется с выводом предупреждающего сообщения.

## Качество кода

- **Стандарт:** ISO C++20 (использование оператора spaceship `<=>`, атрибутов `noexcept` и умных указателей `std::unique_ptr`).
- **Инкапсуляция и повторное использование:** операторы `+=` и `-=` вызывают методы `enrollStudent` и `removeStudent`, устраняя дублирование логики проверки граничных условий.
- **Соответствие статическому анализу SonarCloud:** дружественные операторы и функции объявлены в области видимости класса для корректного поиска имен ADL, соблюдены правила безопасной работы с потоками ввода-вывода и перемещением ресурсов.
