## Цель работы
Расширение программной системы онлайн-школы, разработанной в рамках предыдущей лабораторной работы. Реализация перегруженных операторов для сравнения объектов по различным характеристикам[cite: 4], потокового ввода и вывода данных[cite: 4], управления составом курса с контролем предельной вместимости через операторы `+=` и `-=`[cite: 1, 5], а также реализация дружественной функции для прямого доступа к закрытым членам класса[cite: 4, 8].

---

## Структура проекта
- `Header files/student.h` / `Source files/student.cpp` — класс `Student`: закрытые поля (`studentId`, `studentName`, `completedTasks`)[cite: 4], оператор равенства (`==`)[cite: 4, 8], трехстороннее сравнение (`<=>`)[cite: 4], потоковые операторы (`<<`, `>>`)[cite: 4] и дружественная функция `inspectStudentInternals`[cite: 4, 8].

- `Header files/course.h` / `Source files/course.cpp` — класс `Course`: перегруженные операторы `+=` и `-=` для зачисления и отчисления студентов[cite: 1, 5], контроль лимита участников (`maxCapacity`)[cite: 1, 5], расчет прогресса[cite: 1, 5], а также структура двусвязного списка `CourseList`[cite: 1, 5].

- `Header files/menuFunc.h` / `Source files/menuFunc.cpp` — функции консольного интерфейса (`mainMenu`, `courseMenu`) для управления курсами и студентами[cite: 3, 7].

- `Header files/header.h` — общий заголовочный файл, объединяющий библиотеки и модули проекта[cite: 2].

- `Source files/main.cpp` — точка входа: функция проверки перегруженных операторов и дружественной функции `verifyBasicOperations()`, инициализация начальных данных `populateInitialData()` и запуск главного меню[cite: 6].

---

## Основной функционал

1. **Сравнение объектов по характеристикам:**
   * Реализация оператора равенства (`==`) для сопоставления студентов по уникальному идентификатору `studentId`[cite: 4, 8].
   * Реализация оператора трехстороннего сравнения (`<=>`) стандарта C++20, обеспечивающего автоматическую поддержку операторов `<`, `>`, `<=`, `>=` на основе количества выполненных задач `completedTasks`[cite: 4, 6].

2. **Потоковый ввод и вывод:**
   * Перегрузка оператора `<<` для вывода имени, идентификатора и числа выполненных заданий студента в выходной поток[cite: 4].
   * Перегрузка оператора `>>` для ввода данных о студенте (`studentId`, `studentName`, `completedTasks`) из входного потока с корректной обработкой переносов строк[cite: 4].

3. **Дружественная функция:**
   * Функция `inspectStudentInternals` объявлена как `friend` внутри класса `Student`[cite: 4].
   * Демонстрирует прямой доступ к закрытым полям `studentId`, `studentName` и `completedTasks` в обход методов-геттеров[cite: 4, 8].

4. **Управление составом курса и обработка ограничений:**
   * Перегрузка оператора `+=` для записи студента на курс с проверкой предельной вместимости `maxCapacity` и предотвращением дублирования записей[cite: 1, 5].
   * Перегрузка оператора `-=` для отчисления студента по идентификатору и освобождения места на курсе[cite: 1, 5].
   * Контроль лимитов: при попытке добавить студента сверх вместимости `maxCapacity` операция отклоняется с выводом предупреждающего сообщения[cite: 5, 6].

## Качество кода
- **Стандарт:** ISO C++20 (использование оператора spaceship `<=>`, атрибутов `noexcept` и умных указателей `std::unique_ptr`)[cite: 1, 4].
- **Инкапсуляция и повторное использование:** операторы `+=` и `-=` вызывают методы `enrollStudent` и `removeStudent`, устраняя дублирование логики проверки граничных условий[cite: 5].
- **Соответствие статическому анализу SonarCloud:** дружественные операторы и функции объявлены в области видимости класса для корректного поиска имен ADL, соблюдены правила безопасной работы с потоками ввода-вывода и перемещением ресурсов[cite: 1, 4].
