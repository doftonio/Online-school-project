## Цель работы
Разработка модульного консольного приложения «Система управления онлайн-курсами» для ведения учета слушателей и их успеваемости с использованием базовых концепций ООП (инкапсуляция, сокрытие данных), работы со статическими структурами данных фиксированной емкости и контроля версий через Git.

---

## Структура проекта
* `student.h` / `student.cpp` — класс сущности «Студент» (`Student`): хранение личных данных, уникального номера билета (ID) и счетчика выполненных заданий.
* `course.h` / `course.cpp` — класс-агрегатор «Курс» (`Course`): логика группы, хранение обучающихся в массиве фиксированного размера, расчет успеваемости.
* `menuFunc.h` / `menuFunc.cpp` — вспомогательные функции интерфейса: вывод текстового меню, обработка пользовательского ввода и навигация.
* `header.h` — общий заголовочный файл проекта (подключение базовых библиотек и общих определений).
* `main.cpp` — точка входа в программу: демонстрационный запуск методов классов и запуск цикла интерактивного меню.

---

## Основной функционал
1. **Управление составом группы:** хранение списка обучающихся в массиве фиксированной емкости.
2. **Контроль лимитов и валидация:** проверка ограничения максимальной вместимости группы (`maxCapacity`) перед добавлением и защита от дубликатов по номеру билета (ID).
3. **Учет успеваемости:** фиксация выполненных заданий и автоматический расчет процента освоения программы курса.
4. **Удаление и корректировка данных:** отчисление студентов со сдвигом элементов массива и освобождением места в группе, а также редактирование данных преподавателя.
5. **Интерактивное консольное меню:** управление системой в реальном времени с поддержкой цветовой сообщений.

## Качество кода
Проект декомпозирован по принципу модульности: каждый класс и интерфейсный модуль вынесены в отдельные пары заголовочных и исполняемых файлов (`.h` / `.cpp`), обеспечена защита от повторного включения заголовочных файлов и реализована валидация корректности операций над массивом данных.
