## Цель работы
Расширение программной системы, разработанной в рамках предыдущей лабораторной работы[cite: 1]. Реализация перегруженных операторов для сравнения объектов по различным характеристикам[cite: 1], потокового ввода/вывода данных[cite: 1], управления составом курса с контролем предельной вместимости[cite: 1], а также реализация дружественной функции для безопасного доступа к закрытым членам класса[cite: 1].

---

## Структура проекта
* `Header files/student.h` / `Source files/student.cpp` — класс `Student`: закрытые поля (`studentId`, `studentName`, `completedTasks`), операторы равенства/неравенства (`==`, `!=`), операторы сравнения (`<`, `>`, `<=`, `>=`, `<=>`), потоковые операторы (`<<`, `>>`) и дружественная функция `inspectStudentInternals`[cite: 1].
* `Header files/course.h` / `Source files/course.cpp` — класс `Course`: перегруженные операторы `+=` и `-=` для зачисления и отчисления студентов, управление лимитом участников (`maxCapacity`), а также структура двусвязного списка `CourseList`[cite: 1].
* `Header files/menuFunc.h` / `Source files/menuFunc.cpp` — вспомогательные модули для взаимодействия с пользователем и отрисовки консольного меню.
* `Header files/header.h` — общий конфигурационный заголовочный файл проекта.
* `Source files/main.cpp` — точка входа: функция проверки и демонстрации перегруженных операций `verifyBasicOperations()`, инициализация начальных данных и запуск интерактивного меню.

---

## Основной функционал

1. **Сравнение объектов по характеристикам:**
   * Реализация операторов равенства (`==`) и неравенства (`!=`) по уникальному идентификатору студента (`studentId`)[cite: 1].
   * Реализация перегруженных операторов отношения (`<`, `>`, `<=`, `>=`, `<=>`) для сравнения студентов по прогрессу прохождения курсов (по количеству выполненных заданий `completedTasks`)[cite: 1].

2. **Потоковый ввод и вывод:**
   * Перегрузка оператора `<<` для форматированного вывода данных студента в выходной поток[cite: 1].
   * Перегрузка оператора `>>` для интерактивного ввода параметров студента из входного потока с сохранением целостности данных[cite: 1].

3. **Дружественная функция:**
   * Реализация дружественной функции `inspectStudentInternals`, обладающей прямым доступом к закрытым (`private`) членам класса `Student` для инспекции внутреннего состояния объектов[cite: 1].

4. **Управление составом курса и обработка ограничений:**
   * Перегрузка оператора `+=` для зачисления студента на курс[cite: 1].
   * Перегрузка оператора `-=` для отчисления студента с курса по его идентификатору[cite: 1].
   * Контроль граничных ситуаций: блокировка зачисления при превышении лимита участников (`maxCapacity`) или при попытке повторной записи одного и того же студента[cite: 1].

## Качество кода
* **Стандарт:** ISO C++20.
* **Инкапсуляция и повторное использование:** операторы `+=` и `-=` используют внутренние методы класса без дублирования бизнес-логики.
* **Соответствие статическому анализу SonarCloud:** перегрузка операторов выполнена в соответствии с правилами предотвращения дублирования кода и стандартом поиска имен ADL.
